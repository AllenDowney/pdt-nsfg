# Working in pdt-nsfg

NSFG metadata built to the PublicDataToolkit standard (`../PublicDataToolkit/STANDARD.md`).

- `metadata/` and `build/report.md` are generated by `build/build_slice.py`; edit the build or `build/slice.yaml`.
- `data/` is gitignored and never committed. `data/raw/` links to files in `~/MarriageNSFG`.
- The NSFG codebook doesn't mark missing codes; the build types them by a rule over labels (`nsfg_missing_from_labels`).
- Only the female respondent file is covered: the standard has no level for several files in one release yet.
